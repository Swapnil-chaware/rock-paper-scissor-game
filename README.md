# 🎮 Rock Paper Scissors Game

## 📌 Overview

This is an interactive **Rock Paper Scissors game** built using HTML, CSS, and JavaScript.
The user plays against the computer, which generates a random choice on each turn.

---

## 🌐 Live Demo

👉 https://swapnil-chaware.github.io/rock-paper-scissor-game/

## 🚀 Features

* Interactive gameplay with click-based user input
* Random computer choice generation
* Real-time score tracking (User vs Computer)
* Dynamic result display (Win / Lose / Draw)
* Visual feedback with color changes
* Clean and simple UI design

---

## 🛠️ Technologies Used

* JavaScript (DOM Manipulation, Event Handling)

## ⚙️ How It Works

* User selects **Rock, Paper, or Scissors**
* Computer generates a random choice using JavaScript
* Game logic compares both choices:

  * Rock beats Scissors
  * Paper beats Rock
  * Scissors beats Paper
* Scores are updated dynamically
* Result is displayed with color indication
